# AnalogMeter

Порт прикладу «Analogue meter» Bodmer'а з `TFT_eSPI` на `Adafruit_GFX`.
Використовує лише прошивка дисплея (`-e esp32doit-devkit-v1`), тому лежить
тут, а не в `src/`: PlatformIO збирає приватну бібліотеку лише для тих
середовищ, які включають її заголовок. Вимірювальні прошивки її не бачать.

Геометрію перенесено один в один; замінено роботу з текстом, бо в
`Adafruit_GFX` немає нумерованих шрифтів і `drawCentreString()` /
`drawRightString()` — вони відтворені через `getTextBounds()`.
