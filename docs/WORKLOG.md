# Журнал робіт

**Що тут:** хто, коли, що зробив і навіщо — включно з тим, що зараз лежить у
дереві незакоміченим. Це не дублікат `git log`: git каже, що змінилось у
файлах, а тут сказано, **чому** й **у якому стані** воно зараз — чи зібрано,
чи прошито в плату, чи доведено до кінця.

**Навіщо:** у дереві вже траплялась готова, робоча, але ніде не описана
зміна — довге натискання кнопки дисплея. Наступна модель знайшла її лише
випадково, через `git diff`, і мало не затерла, працюючи в тому ж файлі. Один
рядок тут коштує хвилину й знімає цілий клас таких зіткнень.

**Правило:** запис додається **перед тим, як закінчити роботу**, а не колись
потім. Новіше — зверху. Обґрунтування вимірювань і розрахунків, як і раніше,
йде в [`measurement_core.md`](measurement_core.md); сюди — короткий підсумок і
посилання на нього.

Формат — чотири рядки, більше не треба:

```
## РРРР-ММ-ДД · коротка назва · хто
**Що:**  одним-двома реченнями
**Чому:** причина, а не переказ дифу
**Стан:** у дереві / закомічено <хеш> · зібрано · прошито / не прошито
```

## 2026-09-25 · палітра веб-інтерфейсу з kh-station · Claude Opus 5

**Що:** кольори сайту замінені на палітру сусіднього проєкту
`http://kh-station.local/`: нейтральні сірі замість синьо-чорних, семантика
`#3FB950` / `#E3A008` / `#F05252` / `#DA3633`. Синій `#58A6FF` добраний із
тієї ж родини, бо в kh-station синього немає, а напруга синя за ТЗ §34.4.
Кольори зведені в `:root`, `CHART_JS` читає їх через `pal()`. Заразом
виправлено три місця, де `textContent` отримував HTML-сутність і на екрані
було видно `charge &middot; from voltage`.

**Чому:** два прилади на одному столі виглядали виробами різних контор. До
купи кожен відтінок був вписаний двічі — у CSS і в canvas, — тож правка в
одному місці мовчки лишала графік у старій гамі.

**Стан:** закомічено разом із цим записом · зібрано (4 середовища +
`native` 6/6) · **прошито**, плата на `192.168.1.35`. TFT **не чіпався** — гами сайту й панелі тепер
свідомо різні. Подробиці: [`measurement_core.md`](measurement_core.md),
розділ «Палітра».
